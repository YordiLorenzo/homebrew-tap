# YordiLorenzo Tap

## How do I install these formulae?

`brew install yordilorenzo/tap/<formula>`

Or `brew tap yordilorenzo/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "yordilorenzo/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
